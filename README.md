CS Tutor


A private CS tutoring platform with interactive lessons, a browser-based Python playground, and an AI tutor that nudges instead of spoiling.



🌐 Live site: tutoring.martinwong.me


Overview

CS Tutor is a web-based learning platform for private computer science students. It covers Python fundamentals through competitive programming, featuring animated data structure visualizations, runnable code exercises, instant auto-grading, and an AI tutor — all without requiring any software installation.


Features


Interactive visualizations — Watch arrays get searched, stacks push and pop, and queues move first-in first-out, directly in the browser.
Python playground — Write and run real Python in the browser with no setup required.
AI tutor — Ask anything and receive guided explanations, not direct answers.
Instant auto-grading — Submit code and get results immediately.
Progress tracking — Exercise completion is saved per browser, with homework assignments and due dates in one place.
Leaderboard — Friendly competition to keep students motivated.
